# Font test fixture

`VengTestKern.ttf` is a synthetic TrueType font authored for veng's font-cook tests. It carries
four glyphs (space, `A`, `V`, `T`) with trivial straight-edge outlines, a `cmap`, horizontal
metrics, and a legacy `kern` table with three pairs (`AV`, `VA`, `TA`) so the cook's kerning path is
exercised. It is released to the public domain (CC0); it contains no third-party outline data.
